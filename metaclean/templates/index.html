MetaCleanshared storage
Cleaning options

When enabled, the original is deleted only after a cleaned copy has been created successfully. This cannot guarantee secure erasure on flash storage.

Find and remove duplicate files

Finds exact byte-for-byte duplicates across the accessible storage folder using SHA-256. File names do not need to match. The scan does not change files; you choose which copy to keep before removal.

One selected keeper is retained in every group. Files are rechecked before deletion. Removal uses normal file deletion, not secure erasure.

Host for devices on your local network

Use this machine's CPU and cleaning tools to process uploads from another phone or computer, including iPhone and iPad. Remote uploads are temporary and are returned as a ZIP.

Hosting is off by default. When enabled, only private-network clients with the generated sharing link can access the upload portal. Stop hosting to revoke the link.
